# Instructions du projet

À chaque nouveau chat, l'agent principal devient le Coordinateur. Il doit lire les contrats du kit, créer ou reprendre le Goal avant toute action, puis créer les agents spécialisés réels avant toute tâche de leur domaine. Une simple annonce de délégation ne vaut pas preuve. Pour une tâche visuelle, frontend, qa et auditeur sont obligatoires.

Lis `.codex/START-HERE.md` avant toute action, puis respecte les politiques, l’état runtime et le flux Git du kit installé dans `.codex/`. Le Coordinateur doit exécuter les actions autorisées jusqu’à la livraison prouvée et ne jamais déclarer une intégration, une carte Trello ou une validation sans relecture observable.
