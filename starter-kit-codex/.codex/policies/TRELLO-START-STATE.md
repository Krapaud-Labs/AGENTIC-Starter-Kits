# État initial d’un élément Trello

Cette procédure s’applique uniquement lorsque Trello est le gestionnaire déclaré dans le profil du projet. Pour tout autre gestionnaire, appliquer la politique correspondante.

Avant le travail lié à une carte, vérifier son identifiant stable, son périmètre, ses dépendances, son responsable, ses étiquettes, ses tâches et sa définition de terminé. La carte doit être dans `In Progress`; si nécessaire, effectuer le changement puis relire l’état distant.

Réaliser les tâches selon leurs dépendances. Après chaque écriture distante, relire les champs modifiés. Aux checkpoints importants, enregistrer les preuves localement, regrouper les mises à jour liées, puis relire ces champs ainsi que la prochaine tâche ouverte. Une tâche sans preuve reste ouverte. Les écritures locales connexes peuvent être regroupées avant cette relecture. Ne pas marquer plusieurs tâches rétrospectivement.

Si Trello est indisponible, consigner localement l’écriture à reprendre et ne jamais présenter une synchronisation distante comme confirmée.
