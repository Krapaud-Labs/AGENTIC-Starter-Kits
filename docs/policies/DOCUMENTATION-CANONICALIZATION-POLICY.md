# Politique de documentation canonique

Le kit ne crée pas un nouveau document pour chaque reprise, agent, audit partiel ou correction mineure.

Avant toute rédaction, le Coordinateur recherche le document canonique du sujet et le met à jour. Un nouveau fichier est autorisé uniquement pour un sujet réellement nouveau, une décision indépendante, une preuve finale distincte ou une archive.

Les rapports d agents, captures intermédiaires, traces de test et historiques de conversation restent dans des dossiers d archives ou de preuves dédiés. Ils ne deviennent pas automatiquement des documents de référence.

Avant une initialisation ou une carte documentaire importante, exécuter l audit de structure fourni par le kit. Les collisions de numérotation, artefacts et doublons sont consolidés dans le document ou l archive existante, sans générer une nouvelle série de fichiers.

Une synthèse finale doit pointer vers les preuves existantes. Les anciennes versions sont déplacées vers `archive/` ou marquées `superseded`, sans supprimer une preuve nécessaire.
